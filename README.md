# AI Бухгалтер
Сервис автоматизации бухгалтерии с ИИ-интеграцией 

Цель проекта - повысить эффективность функционирования малых и средних предприятий за счет автоматизации бухгалтерии на базе искусственного интеллекта.

Назначение - сервис предназначен для автоматизации ключевых функций бухгалтерского учёта в малом и среднем бизнесе: приём и распознавание первичных документов, сопоставление оплат и закрывающих документов, автоматическая генерация бухгалтерских проводок, подготовка отчётности и синхронизация с 1С, прогноза кассовых разрывов.
